# Support

Use [GitHub Discussions](https://github.com/Kazemkhani/outbound-intelligence-engine/discussions) for setup questions, architecture discussion, and implementation ideas. Use the issue templates for reproducible bugs and scoped feature proposals.

This is a community-maintained open-source project. Support is best effort; response times are not guaranteed.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) and use GitHub's private reporting flow. Never post credentials, prospect data, or sensitive logs publicly.
